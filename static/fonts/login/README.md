# Tipografías del login

Inter (400, 500 y 600), Playfair Display (700) y Lora (400), según el diseño de Figma.

Los archivos WOFF2 se sirven localmente. Se obtuvieron de Google Fonts y se
redujeron a los caracteres latinos, puntuación y ornamentos que utiliza la pantalla.
Cada familia conserva su licencia SIL Open Font License en esta carpeta.

Fuentes originales y licencias:

- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- https://github.com/google/fonts/tree/main/ofl/lora
